Paint paint.png using labelled.png, regions.png, uv.svg and the six matching model views. Region numbers and colours match guide.json. Keep the exact canvas size and island positions. Use unlit base colour: no baked highlights or shadows. Do not put region numbers, UV lines or backgrounds into the painted image. Use asset-paint-apply to validate geometry and extend edge padding, then bind the finished PNG with a map declaration. Guides are per node/primitive in mesh-local space; they are not a whole-assembly atlas. Keep this guide with the paint source.
